## M0 · 骨架跑通

**范围**
- 后端：FastAPI 应用装配、`config.py`（路径/端口/默认值）、`/api/health`（含设备探测）、`/ws` 心跳、生产模式静态托管、`data/` 初始化。
- 前端：Vite + React + TS；路由（`/` 与 `/lab/:graphId`）；i18n（zh-CN / en，默认跟随浏览器，持久化）；工作台三区布局外壳（allotment）；模型库页（先读 `/api/models` 显示空态）。
- `scripts/`：开发启动脚本（同时起后端与 Vite dev，或生产模式单端口）。

**验收**
1. 执行一条命令后，浏览器打开 `http://localhost:8410` 能看到模型库页面。
2. 右上角可切换中/英，刷新后语言保持。
3. `/api/health` 返回设备信息（CPU / GPU 名称）；页面显示设备徽标。
4. 浏览器控制台与后端日志无报错；WS 心跳可见。

## M1 · 图 IR + 编辑器 + 形状推导

**范围**
- 后端：`graph/ir.py`（IR 模型与校验）、`graph/module.py`（GraphModule 拓扑执行器）、`graph/shapes.py`（dry-run + 缓存）、`graph/presets/`（MLP-MNIST、CNN-MNIST）、`/api/graph/validate`、`/api/graph/infer`、`/api/models`。
- 前端：GraphEditor（xyflow）——节点白名单组件、参数内联编辑、拉线连端口、框选删除、复制粘贴、撤销重做、自动布局；节点形状徽标；只读模式 + "克隆为副本"；本地结构预校验 + 后端形状校验的错误展示。

**验收**
1. 模型库点开预置 CNN，画布上每个节点显示输入/输出形状与参数量（与 PyTorch 实数一致）。
2. 把 `Linear` 的 `out_features` 改错再接到 `Output`，节点标红并给出可读错误（定位到节点）。
3. 连线或改参后 300ms 内形状更新，交互无可感延迟。
4. 预置模型不可直接改（只读），克隆后原模型仍完好无损。

## M2 · 训练管线（真跑 + 实时曲线 + 控制）

**范围**
- 后端：`datasets/`（MNIST 下载 + 缓存 + 加载 + 进度事件 + 手动导入路径）、`runners/base.py`、`runners/torch_runner.py`（训练循环 + 指标事件 + 控制 drain）、`runners/manager.py`（子进程生命周期、reader 线程、看门狗、状态机）、metrics 落库（批量写）、`/api/runs*` 全套。
- 前端：RunControls（启动/暂停/恢复/停止、状态与耗时、step）、MetricsCharts（uPlot：loss / acc / lr / grad_norm / 吞吐）、RunList（历史列表）、runStore 窗口化缓冲。

**验收**
1. 选 MLP + MNIST + 默认超参 → 启动 → 曲线实时增长；epoch 结束有 val 指标。
2. 暂停后曲线停止、状态显示 `paused`，恢复后连续（不丢 step）。
3. 停止后 3s 内子进程退出（任务管理器可见），run 落库为 `stopped`。
4. 训练中把 lr 从 0.001 改到 0.0001，曲线出现可见拐点，且 lr 曲线同步。
5. 关掉浏览器标签再打开，run 列表仍能看到该 run 与其历史曲线。

## M3 · 探针可视化

**范围**
- 后端：`probes/hooks.py`（按配置挂 hook、降采样、量化）、`probes/encode.py`（统一 payload 容器）、快照落盘 + DB 索引 + ETag 拉取接口；`torch_runner` 集成探针（非采样步零开销）；新增预置：字符级小 GPT（中/英小语料）。
- 前端：ProbeViewer（层勾选、kind 切换）、renderers（FeatureGridCanvas / HeatmapCanvas / HistogramCanvas）、colormap 切换与 hover 读真实数值、快照按 URL 拉取并缓存。

**验收**
1. CNN 训练中勾选 `conv1`：特征图网格随 step 更新；hover 显示量化前的真实数值。
2. 小 GPT 训练中可看多头注意力矩阵（含因果掩码上三角为 0）；训练若干 epoch 后注意力模式有肉眼可见变化。
3. 非采样步与不勾选探针时，吞吐与无探针基线差异 < 5%；采样步开销使整体吞吐下降 < 10%（给出对比数字）。
4. 快照文件确实落在 `data/runs/{run_id}/snapshots/`，DB 索引可查。

## M4 · 历史与回放

**范围**
- 后端：run 详情/删除/占用统计、快照索引过滤、metrics 降采样（LTTB）。
- 前端：回放模式（`/lab/:graphId?run=r_xxx`）——恢复图结构（只读）+ 曲线全量 + time slider；游标与快照联动；删除 run / 清理全部历史（含磁盘占用显示）。

**验收**
1. 打开一个已完成 run 的回放，拖动 slider 时曲线游标与探针快照同步变化。
2. 刷新页面后仍处于该回放（URL 可分享/刷新不丢状态）。
3. 删除 run 后：列表消失、`data/runs/{run_id}/` 目录消失、磁盘占用数字更新。
4. 服务重启后，之前的 run 全部可回放（数据不依赖内存）。

## M5 · 算法内容补齐

**范围**
- ML（`ml_runner.py`）：线性/逻辑回归、决策树、随机森林、SVM + 二维合成数据集（moons/circles/blobs/spiral）+ 自实现 step 级迭代；`DecisionBoundaryCanvas`（边界 + 支持向量 / 树深度标注）。
- RL（`rl_runner.py`）：GridWorld（可编辑障碍与奖励）+ 表格 Q-learning；`GridWorldCanvas`（Q 值热力图、策略箭头、轨迹、ε 衰减）。
- DL 补 RNN/LSTM 字符级预置 + `hidden` 热力图。

**验收**
1. 四个 ML 模型的决策边界随迭代逐步成形；决策树能看到边界随深度细化；SVM 能看到间隔与支持向量。
2. RL：策略箭头从随机收敛到直达终点；ε 衰减与回报曲线可见；改障碍后重训结果随之变化。
3. LSTM 训练时能看到隐状态热力图随时间步与训练步的变化。

## M6 · 打磨与交付

**范围**
- 数据集：上传入口（zip / csv / txt）、CIFAR-10 可选下载、镜像地址配置与手动导入说明、缓存状态 UI。
- 体验：双语文案校对（含模型说明、错误信息、事件文案）、空态与错误态、加载骨架屏、键盘快捷键（图编辑器）。
- 性能：曲线 2000 点流畅性、快照拉取 ETag 缓存、dry-run 缓存命中率。
- 交付：README（安装/启动/演示路径三步）、依赖锁定、数据集预下载脚本、`.gitignore`（`data/`）。

**验收**
1. 在一台全新机器上按 README 三步（装依赖 → 起服务 → 打开浏览器）跑通演示路径。
2. 所有已知错误路径（下载失败、图非法、训练崩溃、上传格式错误）都有可读提示，不出现裸异常。
3. 演示路径（模型库 → CNN → 训练 → 探针 → 回放）全程无卡顿、无控制台报错。
4. 中英切换后无残留中文/英文硬编码文案（术语按约定保留英文）。
