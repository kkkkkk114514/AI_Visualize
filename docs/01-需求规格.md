# 01 · 需求规格

> 状态：**定稿 v1**（2026-09-20 需求访谈结论）。变更流程：先改本文档，再改代码。

## 1. 一句话定位

一个运行在本机的 Web 应用：用**真实训练**把机器学习 / 深度学习 / 强化学习模型的**结构与训练过程**变成可交互的可视化，重心在深度学习；界面中英双语，主要用于对外展示。

后续一切功能取舍以三条判据为准：

1. **真实**：训练是真跑的，指标、激活、注意力均来自真实计算，不用假数据替代。
2. **看得懂**：任何一屏都能回答"现在在看什么、它为什么这样变"。
3. **展示不翻车**：开箱即用，演示路径零配置；除数据集首次下载外不依赖网络。

## 2. 使用场景

| 场景 | 说明 | 权重 |
| --- | --- | --- |
| 对外展示 | 打开浏览器 → 模型库 → 点开模型 → 一键跑起来看实时可视化 | **主场景** |
| 自测与实验 | 改网络结构 / 超参，跑多个 run，从历史回看对比 | 次 |
| 理解原理 | 通过真实数据流的可视化理解网络在算什么（v1 不含讲解文案，见 §5） | 次 |

## 3. 功能需求

### FR-1 模型库首页

- 卡片式列表，按 **机器学习 / 深度学习 / 强化学习** 分区；卡片显示：名称（双语）、数据集、任务类型、一句话说明、缩略示意图。
- 点击卡片进入工作台；若该模型有历史 run，卡片上可直接"回放最近一次"。
- 提供"新建空白模型"入口（进入图编辑器）。

### FR-2 工作台（统一外壳 + 按类型装配面板）

三区布局，可拖拽调整宽窄（allotment）：

- **左区 · 配置**：模型配置 + 训练超参（按算法类型装配不同面板）
- **中区 · 主视图**：DL = 图编辑器；ML = 决策边界画布；RL = 网格世界画布
- **右区 · 指标与探针**：实时曲线 + 中间层探针视图
- **顶部 · run 控制条**：启动 / 暂停 / 恢复 / 停止、状态与耗时、当前 step、设备徽标（CPU / GPU）

面板内容由「算法类型 → 面板注册表」决定，新增算法只加面板、不改外壳。

### FR-3 图编辑器（深度学习）

- 基于 `@xyflow/react`：拖拽建节点、拉线连端口、框选 / 删除、复制粘贴、撤销重做、自动布局。
- 节点内联编辑参数（通道数 / 核大小 / 激活函数 / 隐藏维 …），节点上标注**张量形状**（来自后端形状推导）。
- **预置模型可打开**：默认只读，一键"克隆为副本"后可编辑；所有模型（含预置）都由同一份图 IR 驱动。
- 非法操作即时提示：形状不匹配、环路、悬空端口、缺少 Input/Output；保存前必须通过校验。

### FR-4 形状推导与校验

- 以**真实 dry-run** 实现：后端按图 IR 构建 `nn.Module`，喂 dummy 输入跑一次前向，用 hook 收集每节点输出形状与参数量（不手写规则表，避免与实际前向不一致）。
- 接口：`POST /api/graph/validate`、`POST /api/graph/infer`；编辑器在连线 / 改参后 300ms 防抖调用，把形状标注到节点。
- 错误信息必须可读：定位到节点 id 与人类可读名称，说明哪两个形状不兼容、期望什么。

### FR-5 训练控制

- 启动（选数据集 + 超参）→ 运行 → 暂停 → 恢复 → 停止（可强制终止）。
- 训练中**实时调参**（仅两项，明确边界）：学习率（立即生效）、Batch Size（下一 epoch 生效）。
- 同一时刻只允许 **1 个活动 run**（本机展示场景，不做并发调度）；历史 run 可随时回放。

### FR-6 实时指标

- 曲线（uPlot）：loss、accuracy（train / val）、learning rate、gradient norm、吞吐（samples/s）、显存占用（有 GPU 时）。
- 按 step 推送；服务端降采样；前端窗口滑动流畅度优先。
- 曲线数据自动落库，供回放。

### FR-7 中间层探针（实时 + 回放）

- 训练中勾选要观察的层（按网络类型给一组默认推荐层），探针按设定频率（默认每 50 步）采样。
- 可视化形态：**特征图网格**（CNN）、**注意力矩阵**（Transformer，多头）、**隐状态热力图**（RNN / LSTM）、**激活分布直方图**（通用）、**权重快照**（可选）。
- 采样数据降采样 + 量化后存储，前端 canvas 渲染；支持 hover 读数值、colormap 切换。**实时看与事后回看走同一套渲染路径**。
- 开销约束：采样使训练吞吐下降 < 10%；非采样步零额外开销。

### FR-8 训练历史与回放

- run 列表：名称、模型、数据集、超参摘要、最优 / 最终指标、耗时、设备、状态。
- 回放：选中任一历史 run → 恢复当时的图结构 + 曲线 + 探针快照；拖动 time slider 逐 step 回看。
- 删除 run（含快照与权重文件）；显示磁盘占用。

### FR-9 数据集

- **内置**：MNIST、Fashion-MNIST、CIFAR-10（可选下载，体积大）、字符语料（英文 tiny-shakespeare / 中文小语料）、二维合成数据集（moons / circles / blobs / spiral，程序生成）。
- 首次使用某数据集时下载并缓存，显示进度；支持**手动导入**（文件放入 `data/datasets/` 指定目录）与镜像地址配置，应对网络受限。
- **上传入口**（v1 范围有限）：图片数据集（zip，按文件夹名作标签）、CSV 表格、纯文本（字符级语料）。

### FR-10 中英双语

- 全界面中英可切换（react-i18next），默认跟随浏览器语言，选择持久化（localStorage）。
- 覆盖范围：界面文案、模型 / 数据集名称与说明、图表轴标签、错误信息、训练事件文案。
- 领域术语按惯例保留英文（Conv2d、Attention、Learning Rate 等）。

### FR-11 设备自适应

- 启动时探测 CUDA：有 GPU 用 GPU，无则 CPU，界面显示当前设备。
- 模型规模与默认步数按设备给不同默认值（CPU 默认小模型 / 少步数，保证演示流畅）。

## 4. 算法覆盖清单（v1）

### 4.1 深度学习（重心）

| 模型 | 数据 | 可视化重点 |
| --- | --- | --- |
| MLP 分类 | MNIST / Fashion-MNIST / 二维合成 | 全连接结构与权重、logits→概率、混淆矩阵、激活分布 |
| CNN 分类 | MNIST / CIFAR-10（子集） | 卷积核、特征图网格、池化前后对比、逐层形状 |
| RNN / LSTM | 字符级文本 / 序列任务 | 时间步展开、隐状态热力图、逐字符预测概率 |
| Transformer（字符级小 GPT） | 中英小语料 | Embedding、多头注意力矩阵、FFN、下一 token 分布、注意力随训练变化 |
| （自定义）图 IR 任意组合 | 上述任一 | 按勾选的探针层展示 |

### 4.2 机器学习（仅经典监督）

| 模型 | 可视化重点 |
| --- | --- |
| 线性 / 逻辑回归 | 决策边界 / 拟合直线随迭代演进 |
| 决策树 | 决策边界随树的生长逐步细化、树结构图 |
| 随机森林 | 多棵树投票合成的边界、树数量对边界的影响 |
| SVM | 间隔、支持向量高亮、核函数切换下边界变化 |

数据为二维合成数据集（可选上传 CSV）。**不做**无监督、降维、评估调参专题。

### 4.3 强化学习（点缀，仅 1 个）

| 模型 | 环境 | 可视化重点 |
| --- | --- | --- |
| 表格 Q-learning | 内置 GridWorld（可编辑障碍 / 奖励） | Q 值热力图、策略箭头、智能体轨迹、ε 衰减、回报曲线 |

**不做** DQN、PPO 等深度 RL。

## 5. v1 边界与非目标

明确不做（防止范围蔓延，如需要另开版本）：

- 原理讲解文案 / 课程内容、图表导出（PNG / PDF）、引导式自动演示 —— 访谈中已确认为"不需要"。
- 用户账号、云部署、多用户、并发多 run 训练。
- 训练中单步调试器（手动逐层前向）。
- 代码编辑器模式（建模只走节点编辑器 / 参数表单）。
- 导入任意外部 PyTorch / sklearn 模型定义或权重文件。
- 拖拽编辑器支持控制流（if / loop）与自定义算子。
- 移动端适配（桌面浏览器优先，最小宽度 1280px）。

## 6. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 曲线 ≥ 2000 点拖动无卡顿（低端集显笔记本）；探针采样使训练吞吐下降 < 10%；本地首屏 < 2s |
| 稳定 | 训练子进程崩溃 / 被杀不影响服务进程；任何 run 可强制停止；异常必有可读提示与日志 |
| 资源 | 单 run 快照磁盘占用默认 ≤ 100MB；提供单 run 删除与"清理全部历史" |
| 隐私 | 除数据集下载外无外部请求，不上传任何数据 |
| 可维护 | 图 IR、REST、WS、存储 schema 为冻结契约；改契约必须先改 02 文档 |

## 7. 术语表

| 术语 | 含义 |
| --- | --- |
| 图 IR | 描述模型的 JSON 有向无环图（节点 = 层，边 = 张量流），前后端唯一真源 |
| run | 一次训练会话（配置 + 指标 + 探针快照 + 权重），有唯一 id |
| probe | 对某个层的中间结果采样 |
| snapshot | 一次探针采样产出的可视化数据（量化数值数组 + 元数据） |
| 工作台 | 单个模型的可视化与实验界面（`/lab/:graphId`） |
| dry-run | 用 dummy 输入真实跑一次前向，用于形状推导与图校验 |
